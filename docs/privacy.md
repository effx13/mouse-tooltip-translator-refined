# Privacy

- Text you hover, select or type is sent only to the translation engines you enable in the settings, tried in your order until one answers (or to the LLM endpoint or LibreTranslate server you configure).
- Finished translations are cached in your browser (IndexedDB) for 30 days so the same text isn't sent again. You can turn the cache off or clear it in the Engines tab.
- Settings stay in your browser. If you turn on settings sync, they sync through your browser account. API keys and engine settings are never synced.
- Nothing is collected, stored or shared anywhere else.
